# 控制探秘营 · 持久部署说明

## 一、运行结构

```
Windows 计划任务「控制探秘营-期中考试服务」
        │  开机 / 登录时自动触发（S4U，无窗口、无需登录桌面）
        ▼
node service/supervisor.cjs        守护进程：拉起服务、崩溃 3 秒后自动重启
        │
        ▼
node server/index.cjs              HTTP 服务：0.0.0.0:8830
```

- 计划任务以 S4U 方式运行在后台会话，**不弹黑窗口**，锁屏、注销桌面都不影响服务。
- 服务进程异常退出（崩溃、被结束）后，守护进程 3 秒后自动拉起；连续快速失败会逐步拉长到 10 秒 / 60 秒，避免死循环。
- 关掉任何命令行窗口都不会停止服务。

## 三、常用操作

| 操作 | 方法 |
| --- | --- |
| 启动 | 双击 `service\启动服务.cmd`，或双击 `启动控制探秘营.cmd` |
| 停止 | 双击 `service\停止服务.cmd` |
| 查看是否在跑 | `netstat -ano | findstr :8830` |
| 查看运行日志 | `app\data\service.log`（记录每次启动、退出、重启时间与原因） |
| 查看计划任务 | 任务计划程序 → 任务计划程序库 → `控制探秘营-期中考试服务` |

停止是一次性动作：下次开机或登录 Windows 时任务会自动重新启动服务。

## 四、文件说明

| 文件 | 作用 |
| --- | --- |
| `service/supervisor.cjs` | 守护进程（启动、重启、日志、退出） |
| `service/启动服务.cmd` | 通过计划任务启动，失败则直接后台启动 |
| `service/停止服务.cmd` | 写停止标记 → 结束服务与守护进程 |
| `service/STOP.flag` | 临时停止标记，停止流程结束后自动删除（已加入 .gitignore） |
| `app/data/service.log` | 守护与服务运行日志（UTF-8） |
| `app/data/service.pid` | 当前守护进程 PID |

## 五、当前注册参数

- 任务名：`控制探秘营-期中考试服务`
- 执行：`C:\Users\Administrator\AppData\Local\Programs\nodejs\node.exe "service\supervisor.cjs"`
- 工作目录：`...\期中考试\repo\app`
- 触发器：**开机启动** ＋ **Administrator 登录**
- 账户：`JUN\Administrator`，S4U，最高权限
- 设置：不限执行时长、多实例忽略新实例、失败重启 3 次 / 间隔 1 分钟、使用电池时也运行

## 六、换机器 / 重装后如何重建任务

以管理员身份打开 PowerShell，执行：

```powershell
$app  = 'C:\Users\Administrator\Desktop\2026-2027教学备课\六年级 过程与控制\期中考试\repo\app'
$node = 'C:\Users\Administrator\AppData\Local\Programs\nodejs\node.exe'
$name = '控制探秘营-期中考试服务'

$act  = New-ScheduledTaskAction -Execute $node -Argument '"service\supervisor.cjs"' -WorkingDirectory $app
$prin = New-ScheduledTaskPrincipal -UserId "$env:COMPUTERNAME\$env:USERNAME" -LogonType S4U -RunLevel Highest
$t1   = New-ScheduledTaskTrigger -AtStartup
$t2   = New-ScheduledTaskTrigger -AtLogOn -User "$env:USERNAME"
$set  = New-ScheduledTaskSettingsSet -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries `
        -ExecutionTimeLimit ([TimeSpan]::Zero) -MultipleInstances IgnoreNew -StartWhenAvailable `
        -RestartCount 3 -RestartInterval (New-TimeSpan -Minutes 1)

Register-ScheduledTask -TaskName $name -Action $act -Trigger @($t1,$t2) `
  -Principal $prin -Settings $set `
  -Description '控制探秘营期中考试服务：开机自启、异常自动重启、无需登录' -Force

Start-ScheduledTask -TaskName $name
```

## 七、排查

| 现象 | 处理 |
| --- | --- |
| 打不开页面 | `netstat -ano | findstr :8830` 看是否监听；未监听则双击 `service\启动服务.cmd` |
| 端口被占用 | 多半是旧的 `启动控制探秘营.cmd` 前台实例还在跑，先 `service\停止服务.cmd` 再启动 |
| 学生打不开但本机能开 | 检查 Windows 防火墙是否放行 node.exe（专用网络） |
| 服务反复重启 | 看 `app/data/service.log` 的退出原因；常见为数据目录被占用或题库哈希不符 |
| 想彻底不再自启 | 任务计划程序里禁用 `控制探秘营-期中考试服务` |

## 八、注意

- 开机自启依赖 **Administrator 账户已注册的 S4U 凭据**，无需输入密码；如更换系统账户需按第六节重新注册。
- 数据目录固定为 `app\data`，服务以绝对路径写入，与是否登录桌面无关。
- 题库只读：`repo\design\01_questions.json`，服务启动时校验 sha256，不匹配会拒绝启动。

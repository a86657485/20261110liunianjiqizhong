**解锁硬规则**：`本关 answeredCount >= questionCount` 即可进下一关；**不看正确率、不设分数门槛**（`stageUnlockIndependentOfScore=true`）。过关后展示短反馈（见 JSON `stages[].clearFeedback`：可鼓励，**不得**点名本关某题正确选项原文），再回站点地图解锁下一站。

**流程一句话**：登录 → 探秘营站点地图见已解锁站 → 进站答题 → 本关全部作答提交 → 过关反馈 → 解锁下一站 → … → 8 站完成 → 可交主卷看百分／可进挑战站（可跳过）。

**学生端呈现**：
- **一题一页**。
- **带图 24 题（GM01–GM24）**：页顶「回忆当时学习画面」插图，上图下题、全屏少空白；只写 fields 与生图提示，不在本题库生成图片。生图优先 GPT、其次 Gemini；静态优先，必要时短循环轻量动图；面向 Win7 Chrome。`recallCaption`／`recallImagePrompt`／过关语均**不泄答案**。图内不要有题干、对勾或已填好的完整真值表。
- **不带图 32 题（GM25–GM56）及挑战题**：`hasRecallImage=false`，不写回忆插图字段；**须铺满题区，不留空图位**（工程实现时题区由题干／状态微表／选项铺满，禁止留出空白插图框）。
- **未作答选项零高亮**：严禁在学生未作答前给单个待选答案加黄框、发光或小手；只可高亮面板区域或提交按钮。控件引导不泄答案。
- 第7课《与运算·校园安全体验馆》《雨天校园最后一班值日》**只可作回忆素材候选**，不得当本期中玩法或命题模板，不得照搬关卡结构或双条件推箱子奖励。第7课题面全部为新情境。

## 第1课《设备控制处处在》

- **课堂应用：**《机关密室—设备控制逃脱行动》
- **角色／外壳：**探险搭档阿澄、小屿，机械向导小序；六间机关密室逃脱。
- **可作回忆插图的关键画面：**
  1. **光影入口**：昏暗密室／教室里，照明、投影和播放器都在，有人在找开关，要先看清再控制。
  2. **风力机关室**：风扇或风力机关对着叶轮、羽片，旁边有风速和定时旋钮；同一阵风可能吹转叶轮、吹散纸片。
  3. **模式密码间**：洗衣机一类面板，要分清「打开电源」和选择快洗、脱水、煮粥等功能。
  4. **城市控制舱**：街道上的信号灯、车辆等公共设备，提醒学生想「谁在控制、实现什么功能」。
  5. **时间锁档案室／门锁对照**：一边是机械钥匙门锁，一边是指纹或电子密码锁，两扇门都关着，手还没按下。
  6. **导入图也可直接用**：看不清的教室（灯没开、窗帘半拉）；一阵风两种结果；谁让街道有序运行；两种门锁对照。

## 第2课《一分为二开与关》

- **课堂应用：**《机关密室Ⅱ—开与关的秘密》
- **角色／外壳：**延续第1课阿澄、小屿、机械向导小序；看清状态—预测切换—验证规则。
- **可作回忆插图的关键画面：**
  1. **光影档案室**：书桌中央有一盏关节台灯，面板上是 I/O 符号；要分清「按了什么」和「灯现在是什么状态」，重复按同一控制会不会出现新状态。
  2. **三色光密码间**：一盏变光灯只有中间一颗按钮，按下去颜色／状态会一轮一轮变，直到状态重复。
  3. **出口信号控制舱**：迷你路口或实验室里并排三盏信号灯、三个开关，学生先自由试验，再把规则交给小序逐行执行。
  4. **计算思维体验站（选做／考后）：**开关光阵（一组灯的开与关）、代码控制密室（指令、循环、条件）。带图题优先用前三间主线密室，这两项仅作备选。

## 第3课《我是小小控制员》

- **课堂应用：**《校园配送实验室》
- **角色／外壳：**学生是校园小小控制员；岚老师在阅览室等书；配送机器人小达；连续剧情《阅读节前的最后一箱书》。校园俯视／平面配送路线。
- **可作回忆插图的关键画面：**
  1. **先由你来控制**：学生手动开图书车，通道有两个转角，要看车头朝向、走到接收区并停稳。
  2. **把经验交给小达**：任务卡编辑器，按顺序安排「送到、停好、到站提醒」；小达只会按卡片执行，缺了哪一步就停在哪。
  3. **走廊突发状况**：保洁人员在走廊放下整理箱，小达因碰撞保护停住，原方案没法继续，要补一条遇障碍规则。
  4. **写给小达的指令**：指令编辑台，逐条写前进、转向、停止和提醒；程序出错会停在那一步。
  5. **人物辨认**：岚老师（阅读室老师）与轮式配送机器人小达的造型，校园地图／收发室到阅览室的路线。

## 第5课《连续变化的数据》

- **课堂应用：**《噪声监测数据站》（学生端为俯视像素校园 RPG：噪声巡查员走近 NPC 进站）
- **角色／外壳：**校园噪声巡查；监测屏、曲线、阈值红线；小递可出现在奖励「夜巡」里，带图题优先用主线五站。
- **可作回忆插图的关键画面：**
  1. **监测站门口**：广场上有人，监测屏显示分贝数字，旁边「监测器透视」三格（输入—计算—输出）跟着声音卡变化；超标时屏幕泛红。
  2. **数据展示墙**：同一段声音左边是稀疏散点、右边是连续波形／曲线，学生在两点之间点一下读数。
  3. **窗帘教室**：教室里拖窗帘把手，光照表和曲线连续变化；或开始烧水，中途读水温。也可配水表、温度计、车速表等仪表。
  4. **阈值控制室**：一条夜间噪声曲线，上面有可拖动的红色阈值线，报警灯随回放闪烁；换一条线，提示次数会变。
  5. **第5站迁移设计**：给教室噪声监测器定一条阈值，仿真课间教室——阈值太低正常聊天也报，太高喧哗却漏报。（若课堂实际画面是屋顶种植园开水泵，可改用「土壤湿度曲线 + 开泵线 + 植物叶子干湿变化」。）
- **已有静帧：**应用目录 `第5课 连续变化的数据/噪声监测数据站-局域网部署/docs/` 与 `public/assets/` 下课堂截图／像素校园素材（选用时避开写有具体答案或教师统计的大屏图）。

## 第6课《开关量的真与假》

- **课堂应用：**《校园开关站》（文件夹里也曾称「开关量控制站」；课堂对外名以《校园开关站》为准）
- **角色／外壳：**俯视校园地图，按顺序拜访六站 NPC，最后「出门条」考核。
- **可作回忆插图的关键画面：**
  1. **监测站门口·指令哪来**：噪声监测流程图旁边一张对照表——左边「音量」有许多不同读数，右边「指令」只有「发提示／不发提示」两种。
  2. **校园控制室·设备面板**：按指令单去开或关教室灯、饮水机阀门、走廊风扇等，用 1 表示开、0 表示关，没有「开一半」。
  3. **礼堂举牌台·举牌表决**：同学举 0／1 的牌子（去不去野炊、同不同意当班长），统计器最后只给出两种结果。
  4. **真假问答亭**：并排两张校园情景图（例如晴天早上上学、雨天放学后），判断「校门开着」「正在下雨」等句子是真还是假，并写成 1 或 0。
  5. **取反实验室**：一台「取反机」或路灯接线——直接连上时白天灯亮得不对，接上「非」后再分别试白天和夜里。
  6. **统计器工坊（拓展）：**投票统计器的输入—计算—输出示意图，运行后显示「去／不去」。
- **已有静帧：**`第6课 开关量的真与假/6-06kaiguanliang-pub/docs/screenshots/`（若已用 `tools/shots.mjs` 出图）；选用时同样避开答案页和大屏统计。

- **课堂应用：**《与运算·校园安全体验馆》
- **课堂故事名：**《雨天校园最后一班值日》（协助值日老师周老师，检查走廊照明和器材归还）

- **可作回忆插图的关键画面：**
  1. **校园服务台·失物认领**：服务台上要核验姓名和书名，两项都对才能还书；只对一项时书还在台上。
  2. **校园走廊·感应灯**：雨天走廊灯，既要看有没有人进入感应区，又要看百叶调出的光照读数；学生拿着便携巡检仪，比较「有人／无人」和「够暗／不够暗」。

  4. **雨天器材室·独立归还**：毛巾／沥水盘（干或湿）和器材架（归位或未归位），两件都满足才能完成归还。

## 第8课《开关量的或运算》

- **课堂应用：**《郑和远航·或运算》（Godot 课堂版；学生端曾用本机端口 8808）
- **角色／外壳：**航海故事改编的控制演练；角色有小录、港口管事、观察员、补给舱船员，以及现代控制室讲解员。场景依次是开场甲板、港口、海上信号台、补给舱、现代控制室。
- **可作回忆插图的关键画面：**
  1. **开场甲板**：船甲板上一个小展台和左右两只礼物箱，摆一件、两件都摆、或都不摆，展台外观会变（这一步课堂上是试玩，不公布结论）。
  2. **港口展台**：码头库房前，瓷器箱和丝绸箱旁边是展台；管事等客人到来，约定「备好其中一样就能展，两样都有也可以」。
  3. **海上信号台**：船上旗号／信号装置分 A、B 两路，学生先布置再正式运行，把四组记录写进信号日志；旁边可对照「与」和「或」的不同（对照表是回看，不要把完整正确答案烧进回忆图）。
  4. **补给舱修规则**：舱里旧控制规则出了问题，先找出不符合要求的组合，再改规则，四组重跑验收。
  5. **现代控制室（同一屏左右两台）：**左边是门锁台（状态分析表、真值表）；右边是车库升降杆仿真，杆前有按钮盒和车牌识别器，任一个条件满足杆就抬起。
